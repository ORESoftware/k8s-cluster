# Contributing

1. Start from an up-to-date `main` branch.
2. Create a focused feature branch.
3. Follow every applicable `AGENTS.md`.
4. Run formatting, linting, and tests.
5. Open a pull request with the matching Linear issue in the title or body.
6. Resolve conflicts semantically and grep for conflict markers afterward.
7. Avoid git rebase in favor of git merge.

Never include provider credentials, production tokens, or capability-bearing Web Push URLs in commits, fixtures, screenshots, logs, or issue text.
