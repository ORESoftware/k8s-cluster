# Security policy

ClipTown is an early-stage project handling sensitive clipboard content. Do not open public issues containing secrets, plaintext clipboard samples, authentication tokens, private keys, or exploitable vulnerability details.

Report security concerns privately through GitHub's security-advisory flow for the affected repository. Include the affected component, reproduction conditions, impact, and any suggested remediation. Revoke exposed credentials before reporting them.

The project does not claim production readiness until the end-device key-management, authentication, tenant-isolation, sync, and release-signing work tracked in Linear is complete.
